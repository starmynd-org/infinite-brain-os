# Projects: The Project Map

One folder per project, each holding a single PLAN.md with intent, scope, success criteria,
and an inline task checklist. This index is a navigation surface; each PLAN.md owns its own
status.

| Project | Status | Notes |
|---|---|---|
| `_template/` | template | the PLAN.md shape every project starts from |
| `_example/` | example | the filled example project for the starter walkthrough |

Add a row here when you start a project.
