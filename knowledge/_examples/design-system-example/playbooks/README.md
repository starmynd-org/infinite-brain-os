# Playbooks: design-system-example

This folder holds repeatable procedure nodes for the namespace. A playbook is a
step-by-step process that an agent or operator follows for a recurring task in this
design system.

## What goes here

- One node per repeatable task. Examples: `add-a-token.md`, `audit-token-usage.md`,
  `publish-token-export.md`, `review-asset-freshness.md`.
- Each node states: when to run it, inputs, numbered steps, and what done looks like.

## This is an example namespace

In a real design-system namespace, playbook files would live here. This example scaffold
leaves `playbooks/` at the README level.
