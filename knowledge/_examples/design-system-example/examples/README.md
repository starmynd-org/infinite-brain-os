# Examples: design-system-example

This folder holds usage example nodes for the namespace. Each node demonstrates how
approved tokens apply to a specific component or pattern.

## What goes here

- One node per usage pattern or component type. Examples: `button-usage.md`,
  `form-field-usage.md`, `card-usage.md`.
- Each node states: which tokens apply, how they apply, what the result looks like (in
  prose or a code snippet linking to the implementation), and what deviations are not
  approved.
- A usage example is authoritative for its pattern. If a component deviates from the
  example, that is either an error or a canon update is needed.

## What does not go here

Token values and design principles do not repeat here. Reference them by name; do not
copy the value. If you copy the value and the canonical token value changes, the example
becomes stale and incorrect.

## This is an example namespace

`button-usage.md` in this folder is the characteristic usage example node for the
design-system profile. It is illustrative content.
