# Synthesis: design-system-example

This folder holds derived thinking for the namespace. Synthesis is interpretive and
current; it is not raw archive and it is not settled canon.

## What goes here

- Contradiction maps: where two token choices, principles, or examples conflict, and the
  current best resolution.
- Best-current-reading notes: the operator's current synthesized answer on a contested
  design decision.
- What-changed reviews: a dated summary of what moved since the last synthesis.
- Canon-candidate packages: a synthesis proposed for promotion into `canon/`.

## Synthesis vs support (contract G11)

`support/` holds provenance and migration receipts. `synthesis/` holds derived
intellectual work. Do not put migration notes in `synthesis/`; do not put derived
thinking in `support/`.

## This is an example namespace

In a real design-system namespace, synthesis files would accumulate here over time as
contested questions arise. This example scaffold leaves `synthesis/` at the README level.
