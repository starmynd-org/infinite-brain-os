# References: design-system-example

This folder holds external reference nodes for the namespace. Each node links to a
third-party specification, tool, or system that this design system is based on, extends,
or must remain compatible with.

## What goes here

- One node per external reference. Examples: `w3c-wcag-accessibility.md`,
  `figma-token-plugin-schema.md`, `upstream-brand-guide.md`.
- Each node states: what the external system is, why it matters to this design system,
  which local tokens or principles it governs, and a URL or path to the source.
- References are read-only citations. Do not duplicate external content here; link to it.

## Freshness

External references need review when the external specification releases a new version.
Record the version number in the node and flag it for freshness review on each release.

## This is an example namespace

In a real design-system namespace, external references would live here. This example
scaffold leaves `references/` at the README level.
