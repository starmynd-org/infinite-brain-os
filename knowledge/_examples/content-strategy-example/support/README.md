# support/

This folder holds provenance and migration records for this namespace. It is mechanical
and historical.

## What belongs here

- Source-priority tables when angles or pillars were migrated from a legacy content doc
  or brand guide.
- Migration receipts recording which source nodes were processed and what was done with
  each.
- A retrieval eval set (`retrieval-eval.md`) with representative agent queries and
  expected load sets, per `_system/retrieval-eval-rules.md`.

## What does not belong here

- Derived intellectual work. That belongs in `synthesis/`.
- Active angles, pillars, or concepts. Those belong in their respective profile folders.

## Scaffold note

This folder is intentionally minimal in the example namespace. In a real content-strategy
namespace built by migrating from an existing content plan or brand guide, this folder
would hold the migration receipt and source-priority table from that migration. A
`retrieval-eval.md` would be added during the first V2 upgrade of the namespace.
