# Support: doctrine-example

This folder holds provenance and migration records for this namespace.

## What goes here

- Migration receipts: records of where content came from when it was reorganized or
  imported from a legacy source.
- Source-priority tables: when two sources disagree, which one takes precedence and why.
- Reorganization maps: the current-to-target maps for any structural migration.

## What does not go here

Derived thinking goes in `synthesis/`. Knowledge nodes go in their respective folders
(`pillars/`, `concepts/`, etc.). Do not put analytical content in `support/`.

## Boundary note (G11)

`support/` is mechanical and historical. `synthesis/` is interpretive and current. This
boundary is strict. If you are writing something that requires judgment or creates new
understanding, it belongs in `synthesis/`, not here.

## This example scaffold

This folder is empty in the example scaffold. In a real namespace, `support/` grows when
content is migrated in from legacy sources or when source-priority questions arise.
