# Synthesis: doctrine-example

This folder holds derived intellectual work that is neither raw archive nor settled
canon. Synthesis is first-class.

## What goes here

- Contradiction maps: where nodes or sources disagree, and the current best resolution.
- Best-current-reading notes: the operator's current synthesized answer on a contested
  topic.
- What-changed reviews: a dated review of what has shifted since the last synthesis.
- Canon-candidates: synthesis that is proposed for promotion into `canon/`.

## What does not go here

Provenance and migration receipts go in `support/`. Do not put migration history in
`synthesis/`. Do not put open-ended analysis in `canon/`.

## Promotion path

A synthesis node that reaches sufficient confidence becomes a canon-candidate. The
operator reviews it and, if approved, it is compressed into `core-doctrine.md` with a
changelog entry. See `canon/README.md` for the update sequence.

## This example scaffold

This folder is empty in the example scaffold. In a real namespace, synthesis nodes
accumulate as the namespace matures and disputes or revisions emerge.
