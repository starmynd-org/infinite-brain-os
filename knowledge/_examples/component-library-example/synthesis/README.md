# Synthesis: component-library-example

This folder holds derived thinking for the namespace. Synthesis is interpretive and
current; it is not raw archive and it is not settled canon.

## What goes here

- Contradiction maps: where two component records conflict, or where a pattern and a
  component record give different guidance for the same situation.
- Best-current-reading notes: the current synthesized answer on a contested approval
  or composition question.
- Canon-candidate packages: a synthesis proposed for promotion into `canon/`.
- Under-review tracking: notes on components or patterns that are pending approval.

## Synthesis vs support (contract G11)

`support/` holds provenance and migration receipts. `synthesis/` holds derived
intellectual work. Do not put migration notes in `synthesis/`; do not put derived
thinking in `support/`.

## This is an example namespace

In a real component-library namespace, synthesis files would accumulate here over time.
This example scaffold leaves `synthesis/` at the README level.
