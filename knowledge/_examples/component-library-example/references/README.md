# References: component-library-example

This folder holds external reference nodes for the namespace. Each node links to a
third-party library, upstream design system, or specification that this component library
is based on, wraps, or must remain compatible with.

## What goes here

- One node per external reference. Examples: `radix-ui-primitives.md`,
  `aria-authoring-practices.md`, `example-co-design-system-link.md`.
- Each node states: what the external system is, which components or patterns it affects,
  and a URL to the canonical source. Record the version the library is compatible with.

## Freshness

External references need review when the upstream library releases a major version. Record
the compatible version in the node.

## This is an example namespace

In a real component-library namespace, external reference files would live here. This
example scaffold leaves `references/` at the README level.
