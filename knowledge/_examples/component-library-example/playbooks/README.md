# Playbooks: component-library-example

This folder holds repeatable procedure nodes for the namespace. A playbook is a
step-by-step process that an agent or operator follows for a recurring task in this
component library.

## What goes here

- One node per repeatable task. Examples: `add-a-new-component.md`,
  `deprecate-a-component.md`, `audit-component-usage.md`,
  `add-data-table-to-screen.md`.
- Each node states: when to run it, inputs, numbered steps, and what done looks like.

## This is an example namespace

In a real component-library namespace, playbook files would live here. This example
scaffold leaves `playbooks/` at the README level.
