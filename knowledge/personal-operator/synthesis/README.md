# Synthesis: personal-operator

This folder holds derived thinking for the `personal-operator` namespace. Because this is a
reduced-base starter namespace with `canon_posture: none`, its synthesis is light: it carries
no contradiction maps or canon candidates, only the one artifact that makes a mixed
template-and-real namespace usable.

This README is navigational. It carries no node frontmatter.

## Files in this folder

- [[template-vs-real-guide]]: disambiguates which nodes are fictional teaching templates and
  which are real operator doctrine. Read it first when working in this namespace.

## Why synthesis here is minimal

A reduced-base starter namespace is not a serious retrieval target, so it does not accumulate
the contradiction maps, best-current-reading notes, and canon candidates that a full namespace
does. The only derived artifact that earns its place here is the one that prevents an agent
from confusing a template for a fact. If content in this namespace ever matures into real
doctrine worth canonizing, it should be promoted into a serious namespace rather than growing
a synthesis layer here.
