# Swarms

This subtree is the execution and governance overlay for swarm-shaped work inside
`infinite-brain-os`.

This repo is the canonical home for new Infinite Brain swarm work. New durable sprint packages
live under `swarms/Sprints/`. The sibling repo at
`<legacy-root>\swarms` is legacy source-material and should be opened
only when a task explicitly needs historical swarm receipts or migration reference.

Canonical planning still belongs in `projects/` and related knowledge nodes. This
subtree holds sprint execution packages, launch sheets, governance artifacts,
closeouts, and other swarm-specific overlays.

Durable shipped-work history now lives at:

- `swarms/completed/COMPLETED-WORK.md`

Start with:

- `Sprints/`
