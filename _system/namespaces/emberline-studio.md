# emberline-studio

## Summary

The starter's worked example namespace. One canon node (the studio's brand essentials),
one concept (the seasonal collection), and edges into the example entities: the brand
voice rule, the product description skill, the weekly review workflow, and the example
department that assembles them.

Reduced base, thin canon posture, public export class. Everything in it is fictional and
